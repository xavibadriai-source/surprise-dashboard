# Badri's Mission Control Dashboard

A surprise high-quality React-based single-page application (SPA) featuring a Salesforce LWC aesthetic.

## Features
- **Salesforce LWC Look & Feel**: Built with Tailwind CSS using SLDS-inspired color palettes, typography, and card layouts.
- **FC Barcelona Command Center**: Match pulse, league stats, and news feed.
- **CSK (Whistle Podu) Analytics**: Points table status, performance trends, and strategic roadmap.
- **Tavily Live Intelligence**: Simulated live data feeds for real-time sports updates.
- **Responsive Design**: Optimized for desktop and mobile viewing.

## Tech Stack
- React
- Vite
- Tailwind CSS
- Lucide React (Icons)

## Development
To run locally:
```bash
npm install
npm run dev
```
